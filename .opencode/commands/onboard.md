Guide the user through their first complete OpenSpec workflow cycle. This is a teaching experience—you'll do real work in their codebase while explaining each step.

Load the `openspec-onboard` skill and execute it.

Note: This command uses the new naming convention. The workflow commands are now:
- `/init` — create feature branch
- `/plan` — generate proposal, specs, design, tasks
- `/build` — implement tasks
- `/test` — generate tests
- `/check` — verify completeness and compliance
- `/review` — review code against best practices
- `/qa` — validate UI with Playwright
- `/done` — archive the change
